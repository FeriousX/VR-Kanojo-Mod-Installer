# Installation

These instructions apply to VR Kanojo Mod Installer v1.0.0 and the approved reduced profile. Use `VRK-Mod-Installer-v1.0.0.exe` and its matching checksum. This unsigned release has incomplete independent Windows compatibility testing; the confirmed owner environment is documented in the README. The owner manages GitHub publication.

1. Close the game. Back up the game directory and user data; start with a writable disposable copy.
2. Run the single EXE normally; Python and an adjacent Backend folder are not needed. Read the scrollable Windows runtime conditions. Accept explicitly to continue; Decline, Escape or closing that dialog must not authorize installation.
3. Browse to the directory containing `VRKanojo.exe` and `VRKanojo_Data`, or the recognized underscore-name layout. Do not select the Data folder itself. The original 2018 game is required; v1.31 is owner-tested, other builds remain unverified. Validation checks technical evidence, not a folder's name.
4. Keep the framework selected. Choose FeriousX Desktop 1.0.4 or neither. The nine excluded optional groups are not offered or embedded. If an external original Play Without VR plugin is present, do not add Desktop alongside it.
5. Wait for a valid review plan. Check the target, components and file counts. **Technical details** shows exact paths, hashes and plan information. A validation success is not installation consent.
6. Confirm only that reviewed plan to install. Cancel does not authorize writes. The backend revalidates paths, ownership, hashes and approval before modification; failures remain blocked.
7. Wait for verified completion. A matching reinstall may report already installed/no changes required. Do not force replacement of unknown files. The installer does not launch the game; launch it yourself after completion.
8. Keep the displayed job ID and persistent state. See [recovery](RECOVERY.md) and [troubleshooting](TROUBLESHOOTING.md). General upgrades/uninstallation and migration to another account are not qualified workflows.

Installation does not copy game repair files, models or replacement saves. No arbitrary destination, licensing or path-safety bypass is provided.
