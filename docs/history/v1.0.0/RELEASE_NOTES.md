# VR Kanojo Mod Installer v1.0.0

Maintained by **FeriousX** for original VR Kanojo (2018), owner-tested with v1.31. VR-Kanojo (2025) is unsupported. Independent modernization based on ManlyMarco's GPL-licensed HF Patch installer; not an official game update or a full replacement for the historical HF Patch.

## Included

- One self-contained Windows x64 EXE; no separately installed Python or user-managed Backend folder.
- BepInEx 5.4.12 x64, required dependencies and game-specific loader settings.
- Optional FeriousX VR Kanojo Desktop v1.0.4, with up to 6 meters of hand reach, or neither.
- Reviewed file plans and explicit consent, hash/ownership checks, configuration preservation, verified backups and persistent recovery.
- Complete scrollable runtime conditions requiring explicit acceptance before continuing.

Version 1.0.0 applies the final product identity and release naming to the manually tested implementation. Backend, plugins, approved payload, license text, seven-page design and recovery behavior are unchanged.

## Compatibility and limits

Owner-tested base build: **Windows X-Lite Optimum (modified Windows 11 Pro x64)**; fresh installation, reinstallation, game launch and Desktop controls passed with no separate Python installation required. Other Windows configurations and clean stock Windows 10/11 remain **NOT VERIFIED**. This is not a universal compatibility claim. The metadata-repackaged release has packaging/safety checks; it has not been subjected to a new gameplay test.

Unsigned release. Full six-setting interactive display/DPI testing remains unverified. Visible finger clenching is not verified despite the Fist percentage setting. General upgrade/uninstall, guaranteed power-loss durability and hostile-file-race protection are not claimed.

The nine excluded optional groups remain absent: original Play Without VR, Message Center, Mute In Background, Graphics Settings, FPS Counter, Runtime Unity Editor, Script Loader, Uncensor Loader and XUnity Resource Redirector/Common. No game repair/update assets, model collections, replacement saves or legacy configuration menu are bundled. No future menu or release date is promised.

## Download and use

Use `VRK-Mod-Installer-v1.0.0.exe` with its matching `SHA256SUMS.txt`, plus `VRK-Mod-Installer-v1.0.0-Source.zip` for source. Close the game, run the EXE, review the runtime terms, choose the original game's executable folder and review/authorize the exact file plan. The installer does not launch the game. Start with a disposable copy and retain `%LOCALAPPDATA%\FeriousX\VRKMI` for recovery.

See README, installation/troubleshooting/recovery guides and original HF Patch comparison in the source package/repository. Never run original Play Without VR together with FeriousX Desktop. GPL source and separate component notices are supplied; preserve them when redistributing.

The project owner published [VR Kanojo Mod Installer v1.0.0](https://github.com/FeriousX/VR-Kanojo-Mod-Installer/releases/tag/v1.0.0) as a full GitHub Release (not a pre-release), under tag `v1.0.0`.
